ORBE Launcher portable mode

While this file sits next to orbe-launcher.exe, ORBE Launcher keeps its settings, its
download cache and its record of installed apps in the ORBELauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move ORBE Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\ORBE Launcher) instead.
If ORBELauncherData can't be written (for example on a read-only drive), ORBE Launcher says
so and uses %APPDATA%\ORBE Launcher instead.
